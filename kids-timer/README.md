# Kids Timer

A simple, kid-friendly countdown timer website: pick a preset or custom duration, watch a circular countdown, and get an audio alert when time is up.

Plain HTML/CSS/JS, no build step or dependencies.

**Run it:**
- Open `index.html` directly in a browser, or
- Serve it locally, e.g. `python3 -m http.server` (from this directory) and visit `http://localhost:8000`

**Files:**
- `index.html` — page structure and controls
- `styles.css` — styling
- `script.js` — timer logic (countdown, presets, custom duration, pause/reset, alarm sound)
